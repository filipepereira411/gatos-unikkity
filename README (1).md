# 🦄🐱 Gatos Unikitty (`gatos-unikkity`)

Uma página web interativa e colorida dedicada ao universo da **Unikitty!** e do Reino Unikingdom, desenvolvida em HTML, CSS e JavaScript puro.

## ✨ Funcionalidades

- **Ilustração Vetorial (SVG) Interativa:** A Unikitty ganha vida diretamente no navegador com animações suaves.
- **Alternância de Estados de Humor:** Alterne entre o modo **Super Feliz** (brilhos e arco-íris) e o modo **Fúria** (chamas e expressão zangada) com um clique.
- **Gerador de Matéria Brilhante:** Efeito de partículas interativas espalhadas pelo ecrã.
- **Personagens do Unikingdom:** Cartões informativos com detalhes sobre os habitantes principais do reino.

## 📂 Estrutura do Projeto

```text
gatos-unikkity/
├── README.md       # Documentação do projeto
└── unikitty.html   # Aplicação web principal (HTML, CSS e JS integrados)
```

## 🚀 Como Executar

Não é necessária qualquer instalação ou servidor para visualizar o projeto:

1. Faça o download ou clone este repositório:
   ```bash
   git clone https://github.com/filipepereira411/gatos-unikkity.git
   ```
2. Abra a pasta do projeto no seu computador.
3. Faça duplo clique no ficheiro **`unikitty.html`** para o abrir diretamente no seu navegador (Chrome, Firefox, Edge, Safari, etc.).

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Estrutura semântica e gráficos SVG embutidos)
- **CSS3** (Animações `@keyframes`, gradientes e layout responsivo)
- **JavaScript** (Interatividade do DOM e sistema de partículas)
